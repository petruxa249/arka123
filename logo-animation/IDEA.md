# АРКА 123: анимация логотипа

**Идея.** Здание на Мстиславца, 10 состоит из двух домов, соединённых аркой, а зал смотрит на Национальную библиотеку через арочные окна 4 × 3,5 м. Поэтому лоадер «строит» арку из двух опор, а затем камера пролетает сквозь проём, и сайт открывается прямо в окне.

**Лоадер (прогрессивное улучшение):**
- Сборка стартует мгновенно и занимает 0,55 с: раскрывается линия пола, две стороны арки поднимаются и смыкаются наверху, «1» вырастает из пола колонной, «2» и «3» пишутся линией. Счётчик 0 → 123 м² пролетает за 0,5 с.
- Пролёт начинается по `Promise.all([minTimer(600), pageLoaded])`. На быстрой связи это ровно через 600 мс, на медленной связи контур арки мягко пульсирует до `window.onload`.
- Пролёт длится 0,7 с (`power3.inOut`, плавный разгон без рывка): цифры гаснут, проём вырастает на весь экран, оверлей растворяется, Hero-секция проявляется снизу.
- Лоадер показывается один раз за сессию: после первого показа в `sessionStorage` ставится `arka_visited`. При перезагрузке или возврате на главную маленький скрипт в `<head>` прячет оверлей ещё до первой отрисовки, и сайт открывается сразу. Для проверки лоадер можно вызвать снова, добавив `#intro` к адресу.

**Ховер знака в шапке (~0,9 с), в шапке только знак без надписи:** по стеклу проходит световая полоса, по контуру арки бежит блик, цифры и буквы по очереди слегка подпрыгивают.

**Техника:** SVG перерисован по исходникам (арка и цифры стали линиями для stroke-анимации, надпись сохранена точными контурами), GSAP 3.12.5. Учитывается prefers-reduced-motion. Если GSAP не загрузился, лоадер сразу убирается.

**Подключение:**
```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
<script src="arka-logo.js"></script>
<script>
  ArkaLogo.mount(document.querySelector('.brand'), { mark: true }).bindHover();
  ArkaLogo.runLoader(document.querySelector('#loader'), { counter: document.querySelector('#arkaCount'), reveal: document.querySelector('.hero') });
</script>
```
Разметка и стили лоадера и шапки есть в `demo.html`.
