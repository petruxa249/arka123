# АРКА 123 — тестовое задание «Медиа Лайн»

Сайт под ключ для арендного зала «АРКА 123» (Минск, ул. Мстиславца, 10, арочные окна 4 × 3,5 м с видом на Национальную библиотеку). Сделаны все пять частей задания.


На GitHub Pages заявки работают в демо-режиме (хранятся в браузере). Полная версия с сервером и админкой описана ниже.

## Что где лежит

| Часть задания | Папка | Что внутри |
|---|---|---|
| 1. Анимация логотипа | `logo-animation/` | `arka-logo.js` (SVG + GSAP): лоадер ~1,4 с и анимация при наведении. Идея текстом в `IDEA.md` |
| 2. Фирменный персонаж | `mascot/` | Аркадий: 8 сцен, перевод картинок в SVG (`make_paths.py` → `poses.json`), компонент `arkady-plate.js/.css`, исходники в `src-images/`. Идея в `mascot/IDEA.md` |
| 3. Помещение в 3D | `3d-blender/` | Сцена Blender целиком из Python (bpy): `build_scene.py` (зал), `flight/flight_scene_v2.py` (здание и пролёт 6 с с фасада в зал). Рендеры в `renders/` |
| 4. Герой бренда | `mascot/` + сайт | Аркадий в своей позе в каждом разделе, оживает при прокрутке (параллакс, складки золотеют) |
| 5. Готовый сайт | корень | 7 страниц, прелоадер, бронь с календарём, `server.js` (Node, без зависимостей) с админкой заявок. Подробно в `SITE.md` |
| 5. Сайт на WordPress | `wordpress/` | Тема `arka123`: заявки со статусами, календарь броней, форматы и вопросы в админке, уведомления. Установка в `wordpress/README.md` |

## Что под капотом у брони

- **Проверка занятости на сервере:** пересекающуюся бронь сервер не примет, даже если две заявки пришли одновременно.
- **Вебхук с подписью:** при создании, подтверждении и отмене заявки сервер шлёт POST с JSON (`request.created`, `request.confirmed`, `request.cancelled`), подписанный HMAC-SHA256 (`X-Arka-Signature`). Его можно принять в Zapier, Make, n8n или Google Apps Script и сразу создать событие в Google Календаре.
- **Календарь-подписка `.ics`** по отдельному токену (не ключ админки) и **уведомления в Telegram-бота**.
- Всё это есть и в теме WordPress, настраивается в админке без кода. Подробно в `SITE.md`.

## Как запустить

- **Статика:** открыть `index.html` или любой статический хостинг.
- **С бэкендом:** Node.js 18+, `node server.js`, сайт на http://localhost:3000, заявки на `/admin` (ключ создаётся в `data/admin-key.txt` при первом запуске).
- **WordPress:** заархивировать папку `wordpress/arka123` в zip и загрузить через «Внешний вид → Темы → Добавить».
- **3D:** `pip install bpy` (или Blender 4+/5), затем в папке `3d-blender/flight`: `python flight_scene_v2.py -- --t 0 --res 1280x720 --out renders/` (один кадр) или `-- --anim --frames 1-181` (весь пролёт). Остальные параметры описаны в начале скриптов.
