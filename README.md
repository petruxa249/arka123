# АРКА 123 — сайт

Статическая версия для GitHub Pages: 7 страниц (главная с бронью, зал, форматы, цены, вопросы, контакты, политика). Календарь и заявки здесь работают в демо-режиме (данные хранятся только в браузере посетителя).
Полная версия с бэкендом заявок, админкой и календарём (server.js) запускается отдельно на Node.js.

Чтобы обновить сайт на GitHub Pages, загрузите в репозиторий все файлы этой папки с заменой.
